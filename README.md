# Ruse Beauty Studio

Направи модерен premium website за Ruse Beauty Face, Русе — козметичен салон с фокус върху beauty care и лазерна епилация.

Реални данни:

Адрес: ул. „Олимпи Панов“ 19, Русе

Телефон: 0887 871 548

Работно време: Понеделник–Петък 09:00–19:00, Събота 09:00–14:00

Неделя: почивен ден

Дизайнът да е luxury beauty / clean aesthetic — ivory, beige, nude, champagne, тъмни елегантни текстове, serif headings + modern sans-serif. Много whitespace, големи качествени изображения, premium cards и фини анимации. Без ярко розово, лилаво или стандартен beauty template.

Структура:
Hero → За нас → Услуги → Онлайн записване → Галерия → Контакти

Най-важната част е онлайн записването:
Услуга → Специалист → Дата → Свободен час → Данни → Потвърждение

Направи booking-а да изглежда като истински premium booking system, с progress indicator, красив date picker, available time slots, selected/disabled states и smooth transitions.

Използвай само реално потвърдена информация. Ако липсват услуги, цени или специалисти — използвай ясно обозначени DEMO данни, без да ги представяш като реални.

Mobile-first. Целият сайт трябва да изглежда като професионален сайт за 500€+, а не като готов AI template.
И добави и някакви твои снимки но не много AI за да изглежда приятно за окото
